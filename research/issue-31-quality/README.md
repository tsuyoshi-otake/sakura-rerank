## 判断

**現在の1,000件の証拠だけでは、Goldの正解率99.5%とWilson下限99.0%を
認証できない。人手なしのあらゆる方法が不可能だと結論したわけではない。**
同じAIによる追加判定や、同じ辞書・抽出器からの再生成は、この不足を埋めない。
次に試すのは、既に第三者が注釈した資料から読みを取得する小規模な開発用検証である。
新たな人手募集をユーザーへ返さない。外部資料があるだけで品質目標を満たすとはしない。

## 1,000件を全件照合した結果

単位は既存train pilotのcase。20個票batch、機械証拠、5軸の暫定判断、
疑義50件の補足台帳をhashで照合した。全件の原文対応検査は成功している。

| 相互排他的な組合せ | 件数 / 1,000 | 解釈 |
| --- | ---: | --- |
| 五つの軸がすべて通常・支持 | 609 / 60.9% | AIの暫定判断。唯一の正解・独立認証ではない |
| 読み・入力単位・文脈・意味は支持、表記だけに確認点 | 259 / 25.9% | 名称保護や表記方針など。誤りとは限らない |
| 読み・入力単位・文脈・意味のいずれかが未解決 | 132 / 13.2% | 誤りの疑いと情報不足を含む。誤ラベル率ではない |

132件のうち82件は、読み・入力単位・文脈に旗がなく、意味だけに曖昧・不明の
判断がある。表記の確認点はこの82件にも重複し得る。このため、辞書・境界・
構造の照合を増やすだけで残りの意味を確定できるという根拠はない。

一次資料を参照したのは、疑義から選んだ50件中の5件（全体の0.5%）。読み支持3、
文脈上の全語読みとの衝突2であり、完全なラベル認証ではない。無作為監査でないため、
3/5を正解率として全体へ外挿しない。機械照合、AI再読、外部の読み根拠を結合しても、
全軸の独立認証を完了したcaseは0。正解率・品質信頼区間はnullのままにした。

別の確認として、21,425件を2回のAI判定で選別した旧工程は、17,880件（83.4539%）
を両方validとして保持した。その後の旧holdout AI監査では3,576件中174件が非valid、
うち166件が曖昧だった。これは独立の真の誤り率ではないが、「AIが2回validとした」
こと自体を最終品質保証にできない、という既存の問題を再確認する証拠になる。
今回そのholdout本文は開かず、既存の公開集計だけを参照した。

## 何が不足しているか

原文との一致は、保存・転記の整合性を測る。同じ辞書から付与した読みが同じ辞書と
一致することは、生成規則の整合性を測る。どちらも、当該文脈における読み、意味、
入力単位、意図する表記を独立に観測した試行ではない。これらを1,000個の「正解」
としてWilson区間へ投入すると、検査対象をすり替えることになる。

仮に独立で正しく判定された標本がある場合、1,000件では二つの品質条件を満たす
誤り数の上限は3件、3,000件では15件となる。これは閾値の算術的な例であり、
今回のAI判断をその標本として扱わない。最終valid holdout >=3,000という条件も別に必要。
609件だけを採用しても、保持率60.9%の選別済み部分集合となり、一般入力の品質を証明しない。

候補の存在率についても母集団の制限を維持する。凍結生成関数と現在関数のASTは一致し、
Top-32内にNFKC一致が一つあることを採用条件としている。24,064 source spanから
24,058件を生成し、候補不足5・正解非一意1を棄却した。上流も辞書の一意読みを使う。
したがって旧devの高いOracleはこの選別後の母集団についての結果である。
24,058件と後段の21,425件の間の全工程は今回再構成しておらず、単一の完全な
取得ファネルとして扱っていない。これは初回再評価の注意点の確認で、新発見とはしない。

## 人手を新規確保しない代替経路の比較

| 経路 | 得られるもの / 期待効果 | 残る問題と検証コスト |
| --- | --- | --- |
| KWDLCの既存第三者注釈 | JUMAN/KNP解析を人手修正した表層・読み。Sakura辞書で読みを生成する循環を外せる候補 | 本IME課題の99.5%保証は公表資料から確認できない。出典URLがないため全履歴照合にも制限。まずtrain文書50件、最大50 source取得、解析・forward照合1系統 |
| 青空文庫の明示ルビ | 原典に付く読みと表記を対応させる限定制御課題の候補 | rubyタグには読み以外の注記もあり、誤記・文学的表現・分布差がある。注記判別と版/底本確認が必要。今回は文書取得せず仕様調査のみ |
| BCCWJコア | 外部で人手修正された現代日本語の形態論情報 | 公式マニュアルの精度記載はコア99%以上であり、本課題の99.5%・Wilson条件と同じ指標ではない。利用条件、入手と読み/表記/IME境界の対応確認が必要。今回は購入・登録・データ取得なし |

KWDLCの注釈由来、表層/読みの列、区分は
[提供元README](https://github.com/ku-nlp/KWDLC/blob/c6ae49d29eca4e1134c6676d682adf5ed6a25f5a/README.md)
で確認した。公開目的はNLP研究で、原文の権利者の事前許諾や出典URLがない旨と、
削除等の要請に応じた更新方針が記載される。モデル学習や成果物への本文再配布の許諾を
ここから推定しない。この調査ではREADME・commit・ファイル一覧だけを読み、コーパス本文は未取得。

青空文庫は[公式注記仕様](https://www.aozora.gr.jp/annotation/etc.html)で、読み以外の
「ママ」等にもrubyタグを使用する。単純なrb/rt抽出は正解読みの生成器にならない。
[取り扱い規準](https://www.aozora.gr.jp/guide/kijyunn.html)は誤りの可能性と作品ごとの
権利状態を明示する。BCCWJの記載は
[公式マニュアル第5章](https://clrd.ninjal.ac.jp/bccwj/doc/manual/BCCWJ_Manual_05.pdf)冒頭による。
これらの事実からGate A未達と判断したのは、本プロジェクトの基準への適合に関する推論である。

長さ違反、候補欠落も保存し、成功例への置換や穴埋めはしない。

この50件で品質目標を満たしたとしない。元データ・モデル・学習・本番は変更しない。
