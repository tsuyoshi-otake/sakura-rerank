# #33 同読み候補を選び分ける学習信号の監査

2026-11-05。#40/#41の固定比較後、追加学習をせず、同じ50,000件のmixed順位学習データを監査した。**文脈対比の学習信号と新規文章への適用範囲に不足がある。単なる件数増量やモデル変更の前に、訓練側で同読み・異表記・異文脈の証拠を増やす。** これは因果的な性能改善の証明ではなく、次に検証するデータ仮説の根拠である。

## 主な観測

|---|---:|---|

| 4出典・2表記×2文脈を示せた読み | 439読み、該当読み群6,760行（13.520%） | 各群1組の1,756行を証拠として保存。全可能対比例の数でも意味認証済み件数でもない |

4例の証拠は、異なる2つのliteral原表記について各2例、4つの異なる出典ID・左文脈がある場合に固定したselectorで採取した。最大32表記型の境界を持つ保守的な探索であり、存在する全組合せを数えたものではない。原語lemmaや意味の異なりを捏造しない。

辞書Top1で原表記に一致する学習例は40,094/50,000（80.188%）。正例順位は1位40,094、2位5,835、3位2,192、4位1,039、5位466、6位374。誤り修正例は9,906件あるため、「修正例がほぼない」という説明は当たらない。問題は同読み内の異表記/文脈証拠と未見表記への一般化を、単なるTop1/非Top1比率と分けて捉える必要がある点にある。

## 既露出の研究対比への学習側カバー率

旧dev/最終Testは開かず、既に結果を公開した#40/#41の対象IDと原表記だけで照合した。候補生成が正解を返せることと、その選択を教える訓練例があることを分ける。

両方の表記が学習にあった組は13/61（21.31%）、17/63（26.98%）にとどまる。学習側の439対比も語義を確認したGoldではない。これらはカバー率の観測であり、未知の読みを持つ例をモデルが必ず誤ることや、対象語を追加すれば何ポイント改善することを意味しない。特に、**今回見た評価語の不足リストを使って訓練へ埋め戻してはならない。** 新しい採取・選択規則は訓練側だけで定義し、別の未使用評価枠を先に固定する。

## 別の原因候補も区別した

- 原文の左文脈+読みは49,995ユニーク入力、重複5群。同一入力で異なる原表記ラベルを持つ群は0。全モデル入力（context/reading/candidate IDs、lengths、7 features、mask）のbyte hashでも49,995入力・重複5群・正例順位の衝突0。この学習集合内では同一入力のラベル矛盾による不可避な誤りは観測されない。100%というempirical ceilingは実際のモデル性能やGold品質を保証しない。
- 文字単位のhash衝突は存在する。正例側の文脈・読み・対象表記にある4,983文字が4,486 IDへ写り、485 IDで982文字が競合する。衝突ID内の少数文字の出現は21,164/2,614,173文字（約0.81%）。一方、同じ候補集合内で候補の全文字列と長さが同じ数値表現へ写るケースは0行だった。文字衝突が無害とは断定しないが、今回の候補選択の頭打ちを直接説明する証拠にはなっていない。
- #40の条件付き接続は文脈感度を増やしても主比較の区間/対比条件を満たさず、#41の次文字学習はlossを下げても救済増加を上回る破壊を生んだ。今回の教師信号監査はその説明候補を絞るが、学習信号を増やす介入実験なしに因果関係を確定しない。

## 改善の優先順と検証費用

1. **訓練側の文脈対比を増やす設計。** 学習利用可能な原文・読みの証拠から、同読みで異候補が正しく選ばれる例を集める。4出典・表記意図・入力境界・読みのforward確認と履歴を残す。対象語の評価からの逆流を禁止する。期待効果は候補識別の教師信号の増加で、精度幅は未測定。まず既存train poolのread-only feasibilityをCPU秒〜分で集計し、採取可能量と曖昧性を報告する。
2. **同じ件数・構造での対比信号の比較。** feasibilityと品質規則が通った後だけ、C2/初期重み/50,000行/500更新/3 seedsを固定して比較する。総データ量、語彙、モデル構造を同時に変えない。6 fitsは今回の既存環境の実測約85–90秒が目安だが、入力作成・新評価/CPU検証の時間は別。原文一致の上昇をGoldや製品採用へ自動昇格しない。
3. **#42の外部教師を条件付きで調査。** 同じ実候補を文脈から判別できる知識があるか、先に権利・snapshot・学習出典・評価混入を確認する。許可不明のコーパスや教師は採用しない。優位性が実測できた場合だけ別の蒸留計画へ進む。現段階の改善量は不明。
4. **#34の適用判断は独立calibrationで検証。** #41の固定marginではsource-exact破壊率の点推定も0.25%を超えた。今回の評価で閾値を再選択せず、モデル固定後の別データで修正可否を識別する。0.25%を緩和しない。

文字語彙の変更・モデル大型化・LM更新数の追加は、今の観測だけを理由に先行しない。独立Gold品質と最終Testの一回限りという制約は別に残る。
