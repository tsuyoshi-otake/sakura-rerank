### 数値条件の検算

以下は**独立Bernoulli標本を仮定した計画計算**で、現在のコーパスに独立性を認定した結果ではない。
既存のfloat実装を70桁Decimalの直接確率和・逆算と照合し、閾値直前の不合格件数も検証した。
方法の一次資料は[SciPyの二項検定・exact区間](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.binomtest.html)。
安全性の判定は従来どおり片側95%上限<=0.25%、最終報告には両側95%区間も必要である。

| 観測した破壊 H | 片側95%上限<=0.25%に必要な最小 C |
| ---: | ---: |
| 0 | 1,197 |
| 1 | 1,896 |
| 2 | 2,517 |
| 3 | 3,100 |

Goldの**1,000件pilotだけでは、安全性を認証できない**。
仮に全1,000例が元から正解で破壊0でも、上限は0.2991%となる。
C=10,000なら破壊16まで上限条件を満たし、真の破壊率を0.10%と仮定した通過確率は97.30%、
0.15%なら66.42%。これは**安全性条件だけ**の検出力で、改善幅・相関・多重比較・Gate B全体の検出力ではない。
C=3,000では破壊2まで、同じ0.10%仮定の通過確率は42.31%。
離散的な許容破壊件数の境目で検出力は段階的に変わるため、結果を見ながら件数を足す運用は禁止する。
TestのNからCは事前には確定しない。Cが十分になるまで取得する停止則にも変更しない。

残る62接頭辞familyを62独立標本へ読み替えることもできない。
単なる比較用計算として、独立した元正解例が62だけなら破壊0でも上限は4.71695%。
これはKNBCの実効標本数や破壊率上限を推定した値ではなく、行の増殖が独立性の代用にならないことを示す条件付き例である。

ラベル品質も点推定だけでは足りない。
1,000件監査で誤り5件なら点推定99.5%だがWilson下限98.8349%で不合格。
両方の数値条件を満たす最大誤り件数は3件（下限99.1217%）。
3,000件監査なら15件（下限99.1766%）、12,000件監査なら60件（下限99.3570%）となる。
**監査件数と最終valid Test件数は別**であり、これらは正解の真偽を独立に測定できた場合の算術条件にすぎない。
pilotの一致率、AIの自己一致、提供元の人手注釈という来歴だけで、この誤り件数を埋めない。
