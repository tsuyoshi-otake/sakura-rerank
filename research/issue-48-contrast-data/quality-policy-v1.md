# #48 対比データの証拠方針 v1

この方針は訓練側だけのfeasibility集計前に凍結する。既存の教師ラベルを修正せず、別の証拠sidecarへ記録する。人手がいない現状を、人手判定済みという記録やAIの独立性の捏造で埋めない。

## 判定軸と状態

| 軸 | この段階で確認できること | 追加証拠なしには確認できないこと |
|---|---|---|
| 原文 | 固定原文からのliteral対象と左文脈、出典・版・hash | 原文が常に正しいこと、IMEで意図された単位 |
| 読み | 抽出時の辞書一意読み、実converter full-reading経路 | その文脈で著者が意図した読み。辞書の一意性で代用しない |
| 入力境界 | 文字数、左隣の文字種、保持されている位置証拠 | 漢字隣接だけを根拠に不正とすること、形態素をIME確定単位とすること |
| 文脈 | 異なる左文脈・原出典・隔離後のsource component | 異なる文脈が候補の語義を必ず識別できること |
| 意味・用法 | literal表記の異なり | 意味の異なり。同形・異表記を意味ラベルへ自動昇格しない |
| 表記意図 | 明示的な表記正規化の一致を診断用に数えること | 許容表記、固有名、引用、略号を無条件に統合してよいこと |

原文文字列は変更しない。NFKCや平仮名/片仮名の比較キーは、同一の表記意図と**見なしてはいけない**衝突の警告に限る。対象の自動置換、許容正解の追加、評価一致判定には使わない。左文脈内の引用符と漢字隣接は非排他的な確認フラグであり、誤ラベル率には換算しない。右/未来文脈をモデルへ渡さない。

## 訓練用量のfeasibilityと品質の分離

全162,502行を最初の分母に残す。実candidateが欠落、非一意、辞書外経路、入力/候補の切り詰めが必要な行は理由別に数える。候補存在率の分母を有効候補行だけへ変えない。

二つのliteral原表記について各二つの異なる左文脈、四つの出典を保存する。別に四つの**source component**が異なる組も数える。同じ著者や近重複で結びつく文書を独立証拠と扱わない。最大32表記型を調べる既存の保守的selectorを使うため、得られるのは存在を証明した組であり、全組合せ数ではない。

同じ50,000件・Wikipedia25,000/青空25,000の選択案は**容量と信号強度の診断**であり、新しい学習入力の承認ではない。強い対比の予約行には、出典に結びつく読み、対象範囲、意味・用法、表記意図の証拠が必要。既存recordに無い証拠を`verified`として生成しない。状態は `verified_for_stated_axis` / `unresolved` / `contradicted` のいずれかとし、軸を超えた認証を禁止する。

現在の出典は辞書から読みを付けたweak supervision。原文のルビなどを回収する場合も、新しい証拠抽出仕様と出典認証を先に固定する。ルビは読み・対象範囲の証拠であり、IME境界や候補間の意味的正解の一括認証ではない。

## 履歴・停止条件

sidecarは元stable ID、元row hash、方針hash、前record hashを持つLF終端のhash chainとして新規保存する。既存の成果物への上書きは禁止。補足・訂正は新versionのsidecarに旧最終hashを参照して残す。外部に保存するmanifestの終端hashと件数を照合し、途中・末尾の削除も検出する。

必要量または証拠が不足すれば、`insufficient_quantity` / `unresolved_quality` を明示してfitを停止する。今回の集計を見て閾値を緩めない。次の候補は、訓練側の権利確認済み原文から独立した読み証拠を保存すること、または#42の教師診断を別planで登録すること。旧dev/既露出研究評価の個別語からの埋め戻しは禁止する。

Goldの99.5%点推定・Wilson下限99.0%・最終valid3,000件、安全性0.25%、最終Test一回限りは変更しない。本工程の一致率や件数は、それらの合格証拠ではない。
